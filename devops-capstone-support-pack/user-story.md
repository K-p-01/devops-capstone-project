# User Story Template

Use this template for each issue in the GitHub Project board. The assignment asks for a public URL to this file.

## Title

`[Short action-oriented story title]`

## User story

**As a** `[type of user]`, **I need** `[capability]`, **so that** `[business value]`.

## Acceptance criteria

- [ ] Given `[initial context]`, when `[action]`, then `[expected result]`.
- [ ] Invalid inputs return a suitable HTTP status and a useful error message.
- [ ] Automated tests cover the happy path and relevant error paths.

## Tasks

- [ ] Write/adjust tests first (TDD).
- [ ] Implement the smallest change that satisfies the tests.
- [ ] Run tests and lint checks.
- [ ] Update documentation and move the issue on the Kanban board.

## Planning

- **Label:** `enhancement` or `technical debt`
- **Estimate:** `[story points]`
- **Sprint:** `[Sprint 1 / Sprint 2 / Sprint 3]`
- **Status:** `[New Issues / Ice Box / Product Backlog / Sprint Backlog / In Progress / Done]`
