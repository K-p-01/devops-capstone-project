Keep the rest of the IBM template README. Update the title and add the badge after the first heading. Replace `OWNER` and `REPOSITORY` with the actual GitHub owner and repo name.

```markdown
# DevOps Capstone Project
```

The badge only shows success after `.github/workflows/ci-build.yaml` has run successfully at least once. Do not claim a successful build before GitHub Actions confirms it.
